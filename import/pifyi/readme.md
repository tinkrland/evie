# import/pifyi — declared taste, cross-vertical

**medium:** shows, music, books, places (cross-vertical)
**route:** mobile app (ios, android). export and api unverified.
**status:** designed pending route confirmation. categorically different
from every other folder here, in a way that matters.

## what it is (verified 2026-11-04, from the app's own billing)

"share your taste": people post the things they love, with tags and
scenes, and others find recommendations from real people instead of an
algorithm. profiles are customised, personal, corner-of-the-internet
shaped.

## why this is not another watch history

every other source in this folder records **exposure**: what played, what
was logged, what was read. pi.fyi records **declaration**: this person
publicly said they love this thing, by name, with a caption.

that is the closest thing to a taste statement any import can carry, and
it still is not consent to be profiled: a declared favourite is a
self-report, which means it enters as a *strong candidate* with the
claim attached, and the owner still confirms it into a taste context.
"i love this" is a claim about a person, and the person gets to be the
one who decides it counts.

## what it must become

rows per item: title, medium, source = pifyi, plus the person's caption
and tags kept as untrusted evidence text. resolution to evie work ids
afterwards, against the reference catalogues, with the usual honest
failures.

## the traps

1. **scenes and tags are aesthetic vocabulary, not our vocab.** the tag
   system is charming and it is not evie's axes. importing tags as axis
   values would smuggle a foreign taxonomy in through the side door.
   tags stay free text, candidates for the wrangling queue at most.
2. **a repost is not a love.** feeds amplify other people's taste.
   only the owner's own posts count as their declaration.
3. **the "ai" tab in the app is not our business.** nothing from an ai
   surface is imported, ever.

## what to verify

whether an export or api exists for the owner's own posts. if not, the
folder stays blocked with the reason written down.
